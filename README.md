# Назначение приложения

**Happ** — кроссплатформенное приложение для локального управления пользовательскими профилями подключения, созданными на основе технологии **Xray**. Программа предназначена для мобильных устройств и настольных операционных систем и предоставляет возможности для создания, импорта, настройки, редактирования, хранения и использования отдельных конфигураций.

Все операции с конфигурационными параметрами выполняются непосредственно на устройстве пользователя. Happ функционирует автономно и не взаимодействует с удалёнными административными панелями, централизованными системами управления или сторонними сервисами, предназначенными для хранения и обработки пользовательских настроек.

В основе приложения лежит система независимых профилей. Каждый профиль представляет собой отдельную конфигурацию, содержащую параметры подключения, правила маршрутизации, настройки обработки сетевого трафика и дополнительные технические сведения. Такая организация позволяет одновременно хранить несколько профилей, редактировать их независимо друг от друга и быстро переключаться между сохранёнными конфигурациями.

---

# Управление конфигурациями

Happ предоставляет встроенные средства для работы с профилями подключения:

* создание новых конфигураций;
* импорт подготовленных файлов;
* изменение существующих параметров;
* хранение нескольких независимых профилей;
* настройка правил маршрутизации;
* редактирование дополнительных параметров подключения;
* выбор активной конфигурации;
* обновление сохранённых профилей;
* удаление неактуальных записей;
* управление всеми функциями через интерфейс приложения.

Каждый профиль хранится отдельно и имеет собственную структуру данных. Любые изменения затрагивают только выбранную конфигурацию и не оказывают влияния на остальные сохранённые профили.

# Хранение данных

Все пользовательские профили и импортированные конфигурационные файлы сохраняются исключительно во внутреннем хранилище устройства.

Happ не использует облачные сервисы для размещения пользовательских настроек, не выполняет автоматическую синхронизацию между устройствами и не передаёт содержимое конфигураций сторонним платформам или внешним сервисам.

Создание, импорт, изменение, обновление, сохранение, активация и удаление профилей выполняются только локально. Все данные используются исключительно для работы приложения и остаются под контролем пользователя.

# Архитектура и ограничения

Happ является локальным инструментом управления конфигурациями и не предоставляет собственную сетевую инфраструктуру.

Приложение не включает:

* серверные компоненты;
* встроенные VPN-службы;
* прокси-сервисы;
* удалённые механизмы обработки информации;
* каталоги готовых конфигураций;
* автоматические средства поиска, получения или распространения профилей.

Все параметры, необходимые для использования конфигураций, пользователь указывает самостоятельно — вручную либо посредством импорта заранее подготовленных файлов.

Happ не определяет назначение пользовательских профилей и не устанавливает правила их использования. Пользователь самостоятельно выбирает способы применения приложения и несёт ответственность за соблюдение законодательства, действующего в стране или регионе использования.
